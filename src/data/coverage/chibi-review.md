# 荆州至三国建立：内容与史料审校说明

本批接续官渡后的河北整合，重点选录208年前后的荆州局势、赤壁及战后经营，延伸至215年划界、219年荆州变化、三国建国、夷陵、223年托孤与修好、229年孙权称帝。新增25个节点、173条三国关系，两个专题共享相应资料。人物及背景持续选录，完整收录清单见[README](README.md)。

## 事件、背景与作品

新增事件：刘表去世与刘琮归降、孙刘联手抗曹、赤壁后的江陵攻防、刘备经营荆南、孙刘分荆州与湘水划界、濡须一线的反复对峙、孙权受封吴王与改元黄武、白帝托孤与刘禅继位、邓芝出使孙吴，以及独立标识的《三国演义》借东风情节。

新增背景：荆州的郡县与交通；避乱、游学与人口流动；江河、舟船与战争补给。解释州、郡、城和水路的不同层次，补充普通随行家庭、士人迁徙、舟船、粮运和疾病对作战的影响。刘表接纳学士、振赡和学校的具体依据注明为卷6裴注《英雄记》。记载的“疾病”保留史书表述，现代病名需另有研究证据。

新增作品：《论语注》（张昭著录）、诸葛瑾致刘备劝和书。前者依据本传的著述记载，传世版本、卷数与完整文本仍需核校；后者为介绍本传所录笺而使用的现代说明性名称，劝和言辞体现吴方交涉立场，裴松之评论另予提示。

## 时间、关系与文学边界

- 《先主传》的长坂追击在前，孙刘交涉与赤壁在后。修正旧的反向先后连线，保留关系ID；加入同年事件排序与时间先后关系环检查。
- 刘表已在208年赤壁战前去世。原有刘表—赤壁关系改为继承局势的背景影响，说明他在战前的身后影响。
- 赤壁与江陵攻防分别呈现：曹军退兵后，各方仍在江陵、荆南等地继续争取控制。荆南归降叙事采用208—209年前后的范围，具体月次未强定。
- 215年划界、219年荆州丢失、221—222年东征与夷陵、223年修好分别解释。时间先后表达阅读顺序，背景影响表达具体条件与决策。
- 孙权221年受封吴王、222年黄武纪年、229年称帝分开记录。邓芝223年出使与陈震229年庆贺、会盟各有依据。
- 黄盖火攻有《三国志》正文依据。诸葛亮设坛借东风以《三国演义》第49回为文学来源；相关边统一标为文学，隐藏文学时一并收起，文学事件沿关联分支进入。
- “出使 / 交涉”箭头由使者或发信者指向接谈人；“交游 / 友谊”无向。真实人物关系、时代索引、背景影响使用不同关系标签。

## 探索与维护

三国继续使用五阶段精选入口，初次最多8位阶段人物、每次最多6个新关联。点选人物优先展示4个真实直接邻居，用户主动打开知识档案。新增事件可从人物、相邻事件、背景或搜索进入；同年事件依据明确先后关系排序，可见主轴按连续间距排布。

两个专题复用通用组件与三国主数据同步脚本。更新后依次执行 `npm run sync:history`、`npm run update:coverage`、`npm run check:data`、`npm test`、`npm run build`。低内存环境可用 `node --test --test-concurrency=1 scripts/*.test.mjs` 逐文件执行同一套测试。
