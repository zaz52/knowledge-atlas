# 汉末至官渡：本批内容与史料审校说明

本批范围：184年黄巾起事至200年官渡战争，连入202—207年河北后续整合，并保留孙策经营江东的并行支线。人物与事件按当前图谱阅读需求选录，全集和待补名单见[历史内容清单](README.md)。两专题共享的小传、事件、作品与背景，以三国JSON为主数据，通过同步脚本更新。

## 事件、背景与作品

新增9个事件：何进遇害与宫廷变乱、迁都长安与洛阳受创、袁绍取得冀州、兖州争夺、孙策经营江东、下邳之战、易京之战、白马与延津之战、乌巢粮屯被袭。

新增3个背景知识点：外戚、宦官与朝廷决策；州牧与地方军政；灾荒、疫病与民间结社。扩充屯田、转运及耕作者处境的说明。

新增作品：《为袁绍檄豫州文》，陈琳代袁绍撰写，收入《文选》卷44。将其作为政治文书阅读：作者、发文者、争取对象、论战修辞分别理解，文中指控还需对照其他材料核验。

## 时间与关系规则

- 190年关东起兵在前，同年迁都长安发生于讨董战争中；192年朝廷诛董作为后续过程分别解释。
- 官渡获胜与河北控制分阶段叙述。袁绍败后仍掌河北，202年去世后诸子争位，曹操又经多次战争推进整合。
- 白马记关羽斩颜良；延津记曹军作战及文丑之死，具体杀死文丑者保留未定。
- 官渡兵力数字存在争议，引用裴松之对曹军兵数的质疑，介绍采用概括过程。
- 下邳依建安三年标198年；汉历冬月换算到现代公历可能跨年，精确月日需另外核算。
- 孙策江东经营概括195—200年的连续过程；太史慈救孔融等未明纪年的活动使用限定范围。关系时间用于阅读定位，文字明确范围与不确定性。
- “时间先后”表示阅读顺序；“背景 / 影响”说明有材料支持的条件、决策与结果。多个条件共同形成历史变化。
- 人物连线说明从属、合作、军事对抗或具体决策，时代索引提供所属阅读入口。人物早年的交战与后来的从属分别记录。

## 探索与维护

初始画面沿用精选事件和最多8位阶段人物。新增事件通过阶段关系、人物、相邻事件和搜索进入；点选人物聚焦真实关系，详情由用户主动打开，继续沿相关事件、前事后续和作品点击阅读。扩展事件的阶段归属优先读取明确的阶段事件关系。人物或事件初次展开时遵循数据中相关人物的排序，官渡首先显示曹操、袁绍等主要参与者；每条显示连线仍须存在实际关系记录。

依次运行 `npm run sync:history`、`npm run update:coverage`、`npm run check:data`、`npm test` 与 `npm run build`。低可用内存环境可使用 `node --test --test-concurrency=1 scripts/*.test.mjs` 逐文件复核。生成的收录统计列明实际节点、人物、作品、来源条目及去重链接数。
