## 覆盖边界与待办

- 逐人扩写重要经历、社会交往、作品版本与流传；一些人物目前具备两条概括经历，精细年表仍待核对。
- 补入更多女性、地方人物、生产者及不同族群的历史经验，并补充相关研究资料。
- 按时期细化土地、户籍、税役、地方治理、商贸与人口数据，明确区域差异和研究争议。
- 十六国、南北朝、五代十国等目前使用时期索引与代表人物，具体政权分支继续梳理。
- 屯田、九品官人法等线索已建图，制度细节、地区差异与后世演变仍需专题审校。
- 原始史书含编纂立场与叙事选择，在线转录应继续对照校勘本与现代研究；来源条目数量包含跨专题命名空间副本。

## 更新方式

修改专题JSON后运行 `npm run sync:history`，再运行 `npm run update:coverage` 刷新本清单；执行 `npm run check:data` 与 `npm test` 验证。三国汉末资料以三国专题为主，朝代中的共享节点带有 `sharedFrom` 标记。候选清单在历史收录JSON中维护，生成时按名称及别名排除已收录人物。
